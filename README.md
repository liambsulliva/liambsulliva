**Business Systems Analyst** and **Computer Science** graduate. I like to build little side projects in my spare time :D

Here's some of the stuff I've been working on.

### Console homebrew

- [Ghost Trick Vita](https://github.com/liambsulliva/ghost-trick-vita) - An unofficial decompilation and port of Ghost Trick: Phantom Detective for the PlayStation Vita.
- [Melee Vita](https://github.com/liambsulliva/melee-vita) - A native PlayStation Vita port of Super Smash Bros. Melee, built from doldecomp/melee. It ships no game data, so bring your own ISO.
- [Switch React Menu](https://github.com/liambsulliva/switch-react-menu) - A minimalist home menu for the Nintendo Switch, built with React on top of [nx.js](https://github.com/TooTallNate/nx.js).

### Web Apps

- [Routelette](https://routelette.liambsullivan.com) - A mapping app that ingests a starting point and a distance and generates random loops with A*.
- [Kingdra Teambuilder](https://pokedraft.liambsullivan.com) - A Pokémon teambuilder for casual and competitive players, built with Next.js and PokéAPI.
- [HERL Digital Narrative](https://herl.liambsullivan.com) - A digital narrative I made for the Human Engineering Research Lab.
- [The Invisible Hand of UX](https://uxwiki.liambsullivan.com) - My Digital Narrative and Interactive Design capstone, built with Docusaurus.
